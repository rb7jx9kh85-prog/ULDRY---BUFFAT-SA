# Uldry-Buffat SA

Site vitrine statique pour Uldry-Buffat SA, installateurs sanitaires et chauffagistes à Cully.

## Développement

Ouvrir `index.html` dans un navigateur ou servir le dossier avec `python3 -m http.server 8000`.

Le formulaire prépare un courriel dans la messagerie du visiteur ; aucun serveur ni stockage de données n'est utilisé.

## Déploiement Vercel

Framework : `Other`. Répertoire racine : racine du dépôt. Aucun build ni variable d'environnement nécessaires.
